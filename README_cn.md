# ProductStrategistAgent · Scout

> **选品策略师** — 数字产品销售流水线的「研判入口」，专门产出机会研判报告。

**拟人名 / Persona：Scout**（侦察 · 发现值得卖的机会）

[English](README.md)

---

## 职责

产出《机会研判报告》，覆盖：当前热点 → 适合热点的数字产品 → 市场调研 → 竞品分析 → 盈利模式 → 引流销售渠道建议。

## 在流水线中的位置

① **Scout** 研判 → ② Wright 生产 → ③ Buzz 引流 → ④ Vendy 成交 → ⑤ Echo 复盘

## 内置能力

- `hot-trend` — 全球热点扫描与选品
- `anysearch` · `find-skill` — 通用搜索与技能发现

## 约束

聚焦被动收入（排除课程 / 服务 / 代运营）；渠道遵守 Payloadz + PayPal / 小红书（Gumroad / TikTok 不可用）。
